# homework_22_django
Это проект интернет магазина с использованием фреймворка Django. Содержит в себе приложение Catalog.

## Установка
1. Клонируйте репозиторий:
```
git@github.com:RadmilaGMTD/homework_22_django.git
```
2. Установите зависимости:
```
poetry install
```
## Маршрутизация 
Файл **urls.py** управляет основными маршрутами проекта. Маршруты определяются в списке **urlpatterns**.

## Контроллёры
1. Приложение Catalog содержит контроллёр домашней страницы **home.html**.
2. Приложение Catalog содержит контроллёр для ввода контактов пользователя **contacts.html**

## Статические файлы
Проект содержит статические файлы в формате css и js. 

## Проверка работы
1. Запустите сервер:
```
python manage.py runserver
```
2. Откройте веб-браузер и перейдите по URL:
```
http://127.0.0.1:8000
```
